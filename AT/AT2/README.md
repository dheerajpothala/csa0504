\## About



Each PNG file inside `drawio/` is a concept map created using 

\[draw.io](https://app.diagrams.net/) answering the corresponding question 

below. The naming convention `CO1\_AT2\_QX.png` indicates:



\- \*\*CO1\*\* – Course/Module code

\- \*\*AT2\*\* – Assessment Task 2

\- \*\*QX\*\* – Question number (1 through 10)
