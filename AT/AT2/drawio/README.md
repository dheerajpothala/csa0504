# How to Open the `.drawio` Files in This Repo

The diagrams in this repository are saved in **`.drawio`** format (used by [draw.io / diagrams.net](https://app.diagrams.net)). These files look like plain code/XML when opened in a text editor or viewed on GitHub, but they're meant to be opened in the draw.io app to see the actual diagram.

Follow the steps below to view or edit them.

## Option 1: Open Online (No Install Needed)

1. **Download the `.drawio` file** you want to view:
   - Go to the file in this repo on GitHub.
   - Click the **"Download raw file"** button (or the download/raw icon).
   - Save it somewhere you can find it, like your Desktop or Downloads folder.

2. **Go to the draw.io editor**: open [https://app.diagrams.net](https://app.diagrams.net) in your browser.

3. **Open the file from your device**:
   - On the startup screen, click **"Open Existing Diagram"**.
   - Select **"Device"**.
   - Browse to where you saved the file and select it.
   - The diagram will open and you can view, edit, or export it.

## Option 2: Use the Desktop App

If you'd rather not use the browser version:

1. Download and install the draw.io desktop app from [https://github.com/jgraph/drawio-desktop/releases](https://github.com/jgraph/drawio-desktop/releases) (available for Windows, Mac, and Linux).
2. Open the app.
3. Go to **File > Open** and select the downloaded `.drawio` file.

## Option 3: VS Code Extension (For Developers)

If you already work in VS Code:

1. Install the **"Draw.io Integration"** extension from the VS Code marketplace.
2. Open the repo folder in VS Code.
3. Click directly on any `.drawio` file — it will open as a visual diagram right inside the editor (no download needed).

## Quick Tip

You don't have to download files one by one — you can also clone or download the entire repository as a ZIP, then open any `.drawio` file inside it using the steps above.

---

**Note:** These files will look like unreadable code (XML) if opened in Notepad, a code editor without the draw.io extension, or GitHub's default file preview. That's expected — always open them through draw.io (web, desktop, or the VS Code extension) to see the actual diagram.
